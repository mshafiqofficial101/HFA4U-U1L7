# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the interest earned or payable on a principal amount based on the rate of interest and the time period. It uses a Bash script to perform the calculation.

## Formula
**Simple Interest = (Principal × Rate × Time) / 100**

Where:
- **Principal:** The initial amount of money.
- **Rate:** The annual rate of interest in percentage.
- **Time:** The time period in years.

## Usage
Run the `simple-interest.sh` script in a Bash terminal. Enter the principal amount, rate of interest, and time period when prompted. The script calculates and displays the simple interest.

## Example
- Principal: 1000
- Rate of Interest: 5%
- Time: 2 years
- Simple Interest: 100
